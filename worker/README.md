# line-dance-proxy — stepsheet proxy as a Cloudflare Worker

Gives the static deployment (GitHub Pages) live stepsheet search by
porting the Python proxy (`server.py` + `sources.py`) to a Worker.
Vanilla JS, zero npm dependencies, no build step.

## Endpoints

- `GET /api/ping` → `{ok:true, mode:"proxy", sources:["copperknob","linedancerweb"], audio:false}`
  — the feature probe the frontend uses to detect proxy mode.
- `GET /api/search?q=…&source=copperknob|linedancerweb|all&level=&wall=&count_from=&count_to=&lang=`
  → `{results:[{url,title,choreo,count,wall,level,music,source}], errors?}` — same
  shape and round-robin merge as `server.py`.
- `GET /api/sheet?url=…` → `{title, url, text}` — normalized CopperKnob-ish
  stepsheet text, byte-identical to what `sources.py` produces (the whole
  scraper stack is ported: CopperKnob HTML scraping and the Linedancer
  search POST + PDF text extractor). Responses are cached at the edge for
  24h, so repeat loads of the same sheet never re-hit the source site.

Audio analysis / YouTube endpoints (`/api/music`, `/api/audio`,
`/api/transcript`) are **not** ported — the UI degrades to tap-tempo +
manual sync, exactly like plain static mode.

CORS allows `https://fionakp.github.io` and `http://localhost:<any port>`,
GET only. Upstream failures come back as clean JSON (`{"error": …}`, 502).
Politeness matches `sources.py`: one upstream page (or page + PDF pair)
per API call, 20-second timeouts, browser User-Agent, no crawling.

## Deploy (one time)

```sh
cd worker
npx wrangler login     # opens the browser to authorize your Cloudflare account
npx wrangler deploy    # prints the worker URL, e.g. https://line-dance-proxy.<you>.workers.dev
```

Then wire the frontend to it — a one-line change in `index.html`: find
`PROXY_BASE` near the top of the script and paste the URL into the empty
string:

```js
})("https://line-dance-proxy.YOUR-SUBDOMAIN.workers.dev");
```

Publish the site as usual. Pages visitors now get "proxy" mode: live
search and sheet loading through the worker, bundled library when the
search box is empty, tap-tempo music sync.

## Test

```sh
node worker/test.js    # zero-dep; runs the port against saved pages/PDFs
```

`test.js` imports the worker's pure parsing functions and checks them
against real CopperKnob pages and Linedancer PDFs saved in `testdata/`,
asserting output identical to `testdata/reference.json` — which was
generated by running `sources.py` on the same inputs. Two synthetic PDFs
cover the ASCII85 and /ObjStm extractor paths the real corpus doesn't
exercise. If you change `sources.py`'s normalization, regenerate the
reference by re-running the corresponding `sources.py` functions on the
files in `testdata/` and updating `reference.json`.

For a live end-to-end check without deploying:

```sh
cd worker && npx wrangler dev          # local worker on http://localhost:8787
python3 -m http.server 8161            # serve the repo statically, separate shell
# open http://localhost:8161/index.html?proxy=http://localhost:8787
```

The `?proxy=` query parameter overrides `PROXY_BASE` for exactly this kind
of testing.
